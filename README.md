# Avani K S — S5 ECA Campaign Website

## Run locally
1. Extract this folder.
2. Ensure `assets/avani-ks.jpg` is present.
3. Open the folder in VS Code.
4. Use the Live Server extension on `index.html` for the best experience.

The page uses Google Fonts, GSAP/ScrollTrigger, and canvas-confetti via CDN, so those enhancements need an internet connection. Basic content and scrolling remain usable without animation libraries.

## Replace the candidate photo
Replace `assets/avani-ks.jpg` with your new candidate image (keep the same filename), or update both image paths in `index.html`.

## Edit content
Edit the Malayalam text directly in `index.html`. The campaign is a front-end support interaction only; the CTA does not cast or register an official election vote.
